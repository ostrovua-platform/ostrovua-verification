Реєстрація проєкту

Проєкт реєструє координатор — автор зберігається в базі автоматично.

🪪 Підтвердження особи

Верифікація за біометричним паспортом через NFC у мобільному застосунку OstrovUA. Значок «Верифіковано» підвищує довіру до профілю.

🔒 Паспортні дані не зберігаються. Дані, селфі та чип звіряються на телефоні; на сервер іде лише результат (так/ні) — ні номера, ні фото, ні MRZ.

🔌 Підключення до API

Вкажи адресу Hasura GraphQL та Admin Secret. Дані зберігаються в браузері локально.

Локально: http://localhost:8080/v1/graphql
На VPS: https://yourdomain.com/v1/graphql

Надішлемо лист із посиланням. Людина перейде за ним, придумає пароль — і одразу матиме доступ до бази.
